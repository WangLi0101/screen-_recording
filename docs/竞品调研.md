# 屏幕录制软件竞品调研

> 调研时间：2026-11-16　｜　调研方式：产品官网功能页、官方文档、公开资料　｜　用途：为《屏幕录制需求文档》确定功能范围与优先级
>
> 说明：本调研用于判断功能方向与市场空位，矩阵中的 ✓ / ◐ / — 为基于公开资料的定性判断，不代表精确评测；付费策略、免费额度等以各产品官网当前信息为准。

---

## 1. 结论先行

1. **"能录"已经不是门槛。** 系统自带工具（Windows 截图工具、macOS `Cmd+Shift+5`）已覆盖"全屏/区域 + 麦克风"的基础需求，纯录制工具没有生存空间。
2. **差异化集中在录制之后：** 自动缩放、光标平滑/点击高亮、背景圆角阴影、字幕转录、文本剪辑、AI 摘要。Screen Studio、Camtasia、Loom 都在往这个方向堆能力。
3. **"一键开录 + 全局快捷键 + 托盘常驻"决定留存。** Loom、CleanShot X、ShareX 的核心体验都是"不打开主界面也能开始录"。
4. **系统音频是最大的技术分水岭，也是最大的翻车点。** Windows 走 loopback 相对成熟；macOS 14.2+ 需要 CoreAudio Tap 与独立 TCC 授权（缺失时表现为"有音轨但永远静音"，不报错）；Linux Wayland 受 portal 限制。
5. **本地优先是明确的空位。** Loom 强绑定云端与账号，Screen Studio 只有 macOS 且订阅制，OBS/Camtasia 过重。**"Windows 优先 + 本地处理 + 轻量 + 录制后自动美化"** 是当前竞争最薄的位置。
6. **2025–2026 的分水岭功能是 AI：** 转录字幕、去填充词、按文本剪辑、AI 摘要/章节/翻译，已从"加分项"变成"预期项"。

## 2. 市场分层

| 分层 | 代表产品 | 用户心智 | 典型短板 |
| --- | --- | --- | --- |
| A. 专业制作型 | OBS Studio、Camtasia、ScreenFlow、Bandicam、ApowerREC | "我要完全控制画面、音频、多轨" | 学习成本高、启动慢、界面重 |
| B. 沟通协作型 | Loom、Zight、Tella、Screen Studio、CleanShot X | "录完立刻发链接/发文件，看起来专业" | 依赖账号/云、订阅制、平台受限 |
| C. 轻量工具型 | ShareX、Screenity、Kap、系统自带 | "按一下就录，别烦我" | 编辑弱、无美化、无协作 |
| D. 国内工具型 | EV 录屏、傲软录屏、迅捷屏幕录制、剪映（录屏入口） | "免费、无水印、中文、能直播" | 广告/捆绑、UI 老旧、隐私顾虑 |

## 5. 关键洞察（对需求的直接输入）

### 5.1 采集层：必备能力已经收敛

全屏/窗口/区域三选一、麦克风、系统音频、摄像头叠加，是**所有付费产品的功能下限**。缺任何一项都会直接被判定为"不完整"。其中：

- **区域录制**在 Electron 里无法通过 `getDisplayMedia` 直接指定，必须"整屏采集 + 后期裁剪"，这会影响画质与性能预算（见《技术方案》§5.2）。
- **系统音频**的平台差异极大：Windows 走 loopback 基本可用；macOS 13+ 可用但 14.2+ 需要 `NSAudioCaptureUsageDescription` 与"系统音频录制"权限，**权限缺失时不报错、只给你一条永远静音的音轨**；Linux 仅在 PipeWire 下可用且一次只能一个源。
- **摄像头画中画**是 Loom 的心智符号，但对录屏工具属于 P1：它显著增加合成与导出复杂度。

### 5.2 交互层：三条硬性体验指标

1. **从唤起应用到开始录制 ≤ 3 次操作**（快捷键 → 选源 → 录）。
2. **录制中控制条不抢焦点、不被录进画面**（Loom、Screen Studio 都做了这件事）。
3. **结束录制后 2 秒内能看到预览并可播放**（不等转码）。

### 5.3 编辑层：从"剪"转向"自动美化"

| 能力 | 用户价值 | 实现成本 | 我们的判断 |
| --- | --- | --- | --- |
| 裁剪头尾 / 去静音段 | 高 | 低 | **P0** |
| 光标放大 / 点击高亮 | 高（教学、演示） | 中 | **P1** |
| 自动缩放（跟随鼠标/点击） | 很高（演示视频质感） | 高 | **P1**（差异化核心） |
| 背景/圆角/阴影/内边距 | 高（"看起来很专业"） | 低 | **P1**（性价比最高） |
| 字幕 / 转录 | 很高 | 中（本地 Whisper） | **P1/P2** |
| 按文本剪辑、去填充词 | 高 | 高 | **P2** |
| 多轨时间线 | 中（专业用户） | 很高 | **P2 / 不做** |

### 5.4 输出与分享

- **MP4/H.264 是唯一刚需容器**，WebM 用于网页嵌入，GIF 用于 IM/文档。
- 录屏场景的真实分辨率分布是 1080p 为主、2K/4K 增长中，**60fps 只对游戏/动画有意义**，默认 30fps 更省资源。
- **分享链接是 Loom 的护城河，也是自建产品的成本黑洞**（存储、转码、鉴权、CDN、合规）。本地优先产品应把"导出文件 + 复制到剪贴板 + 打开所在文件夹"做到极致，把云分享放到 P2 并做成可插拔。

### 5.5 信任与隐私

- 录屏软件权限极高（屏幕 + 麦克风 + 摄像头 + 全局键盘），**用户对"是否上传"极度敏感**。
- Screen Studio 明确把"离线优先、本地转录、上传前告知"做成卖点，这是可直接借鉴的定位。
- 需要：录制前明确提示采集范围、录制中常驻指示器、敏感信息遮罩、默认关闭遥测、上传前二次确认。

## 6. 机会点与产品定位

**定位一句话：Windows 优先、本地优先、开箱即用的轻量录屏工具，录完自动变"能发出去"的视频。**

```
        专业/重
          │   OBS ●        ● Camtasia
          │        ● ScreenFlow
          │   ● Bandicam      ● ApowerREC
          │
          │        ● EV录屏
  ────────┼───────────────────────────  云端/协作
          │              ● Loom
          │   ● ShareX
          │        ★ 我们
          │   ● Screenity     ● Screen Studio
          │   ● 系统自带      ● CleanShot X
          │
        轻量/本地
```

三条差异化主线：

1. **零配置开录**：全局快捷键 → 记住上次源 → 倒计时 → 录。控制条不抢焦点、不入镜。
2. **录完即好看**：自动裁剪空白头尾、光标点击高亮、背景圆角阴影、一键导出预设（1080p/4K/ GIF/仅音频）。
3. **可信的本地工具**：默认不上传、崩溃可恢复、分段落盘、权限状态可视化。

明确不做（至少 V1 不做）：多轨专业剪辑、直播推流、游戏高帧率采集、DRM 内容录制、团队协作后端。
